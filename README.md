# spain-dnv-consultant

## Что это

Шаблон-репозиторий для LLM-ассистентов (Claude Code, Qwen Code, Codex, Kimi
и др.): **персональный консультант** по самостоятельной подаче и продлению
(*renovación*) испанского ВНЖ цифрового кочевника (*teletrabajo de carácter
internacional*, Ley 14/2013).

Рассчитан на один архетип: *autónomo* / независимый контрактор иностранного
заказчика — соло или с супругом/супругой (*cónyuge*) как зависимым членом семьи.
Наёмная работа (por cuenta ajena) и дети как основные заявители — вне охвата;
консультант скажет об этом прямо, а не будет подгонять.

Контент — на русском с испанской юридической терминологией.

## Как это работает

Клонируете репозиторий, открываете папку в своём LLM-ассистенте и начинаете
разговор. Консультант предложит сценарии:

1. **Первичная подача** — собираем документы и подаём на авторизацию
2. **Продление** — готовим пакет на renovación
3. **Консультация** — вопрос по кейсу, разбор ситуации, проверка документов
4. **TIE / huellas** — после одобрения: биометрия, EX-17, tasa 012, recogida
5. **Эскалация** — silencio positivo, requerimiento, отказ, Defensor del Pueblo

Выбираете сценарий — консультант задаёт вопросы в диалоге (не анкетой),
собирает контекст и генерирует **пошаговый план действий**: что делать, когда,
куда идти, что нажать. Каждая карточка плана — самодостаточный гайд с двумя
слоями:

- **По закону** — что требуют норма и официальные документы (с тегом
  достоверности и ссылкой на источник в `knowledge_base/`)
- **По практике** — что реально делали люди в похожих кейсах (из дайджеста
  сообщества или из ваших собственных выгрузок Telegram-чатов)

Если закон и практика расходятся — консультант покажет расхождение явно
и даст рекомендацию с trade-off. Финальный выбор за вами.

Консультант также **проактивно предложит** скинуть свежие выгрузки из
Telegram-чатов по DNV, если у вас есть — он извлечёт из них релевантные
кейсы и учтёт в плане. Данные останутся локально, в git ничего не попадёт.

План — живой документ: по мере разговора карточки обновляются, добавляются
новые при обнаружении проблем, сроки пересчитываются. Можно кидать скриншоты,
задавать уточнения, просить совета — консультант ведёт кейс как живой диалог.

Из установки — только Python 3 для локальных скриптов (заполнение форм,
проверка полей, анонимизация чатов); pip-пакеты не нужны.

> ⚠️ **Это не юридическая консультация.** Консультант делает черновики, которые
> вы проверяете сами по официальным источникам; он никогда не подаёт заявление,
> не платит *tasa* и не регистрирует ничего от вашего имени. Прочитайте
> [LEGAL_DISCLAIMER.md](LEGAL_DISCLAIMER.md) перед использованием.

## Что внутри

### База знаний (`knowledge_base/`)

Структурированный справочник по DNV, переякоренный на дословные тексты законов:

- **`sources/primary/`** — дословные тексты Ley 14/2013, Instrucción conjunta
  2023, Real Decreto и Orden с BOE. Якорь для тега `[норма]`.
- **`norms/`** — разбор норм с as-of датами и ссылками на primary.
- **`practice/`** — обезличенный дайджест практики из Telegram-сообществ
  (мнение, не закон).
- **`forms/`** — реестр полей форм (MI-T, MI-F, EX-17, tasa 790-038/012)
  с гейтами применимости и подсказками по частым ошибкам.

При расхождении `norms/` и `sources/primary/` прав всегда `primary/`.

### Инструменты (`engine/scripts/`)

Python-утилиты, которые консультант вызывает когда нужно:

- **fill_forms.py** — заполняет черновики форм из профиля через реестр полей.
  Нет данных → `[ТРЕБУЕТСЯ: …]`, не выдумка.
- **field_qa.py** — сверяет черновики с профилем: OK / WRONG / MISSING /
  UNCERTAIN на каждое поле.
- **extract_claims.py** — извлекает утверждения из spec для верификации.
- **chat/** — анонимизация и агрегация выгрузок Telegram-чатов в дайджест
  практики (merge → anonymize → filter → slice → build_digest).

### Шаблоны (`templates/`)

- **spec_renewal.template.md** — структура спецификации кейса (обе ветки:
  initial и renovación).
- **memoria.template.md** — структура memoria descriptiva (собирается в конце,
  когда все документы на руках).
- **escrito_*.template.md** — шаблоны для эскалации (recordatorio, agilización,
  silencio positivo, queja al Defensor).

### Навыки и агенты (`.claude/`)

Детальная доменная логика — внутренние справочники консультанта:
сбор контекста, живая верификация фактов, заполнение форм, верификация claim'ов,
трёхслойное ревью, подготовка пакета, ведение после подачи, последняя миля TIE.
Три агента-субагента: devils-advocate (скептик-верификатор), field-qa-reviewer
(независимая ре-деривация полей), official-reviewer (чтение «глазами UGE»).

## Пример

`example/mvp-case/` — синтетический сквозной пример с фиктивными значениями:
профиль, черновики форм, отчёт field-QA. Можно прогнать локально:

```bash
python engine/scripts/fill_forms.py example/mvp-case/case-profile.json \
  knowledge_base/forms/registry.json --out-dir example/mvp-case/drafts \
  --allowed-root example/mvp-case

python engine/scripts/field_qa.py example/mvp-case/case-profile.json \
  knowledge_base/forms/registry.json example/mvp-case/drafts/drafts.json \
  --out-dir example/mvp-case/drafts --allowed-root example/mvp-case
```

Ожидаемый результат: `fields=82 OK=77 WRONG=0 MISSING=5`.

## Приватность

Все персональные данные живут только в `user/` — рекурсивно gitignored.
Никогда не выносите значения профиля (имя, NIE, паспорт, доход, адрес, REGAGE)
за пределы `user/`. Практика сообщества републикуется только как обезличенный
агрегированный дайджест — без сырых сообщений и имён.

## Совместимость с LLM-инструментами

Проект **не привязан к конкретному инструменту**. Точка входа — `CLAUDE.md`,
который читают Claude Code, Qwen Code, Cursor, OpenAI Codex и большинство
современных LLM-ассистентов для кода. Навыки в `.claude/skills/` — обычный
markdown; любой LLM прочитает их, когда `CLAUDE.md` укажет на них как на
внутренние справочники.

| Инструмент | Что читает автоматически | Действие |
|---|---|---|
| Claude Code | `CLAUDE.md` + `.claude/skills/` + `.claude/agents/` | Ничего — работает из коробки |
| Qwen Code | `CLAUDE.md` | Ничего — работает из коробки |
| Cursor | `CLAUDE.md` (если включено) | Ничего или включить в настройках |
| OpenAI Codex | `AGENTS.md` | Скопировать `CLAUDE.md` → `AGENTS.md` |
| Другие | Зависит от инструмента | Скопировать `CLAUDE.md` в нужный файл |

Проект не требует MCP-серверов, специальных API или плагинов — только
способность LLM читать файлы из репозитория и запускать Python-скрипты
(опционально, для заполнения форм и проверки полей).
