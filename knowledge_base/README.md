# knowledge_base/ — курируемая PII-free база

Фундамент движка: **дистиллят норм + обезличенный дайджест практики + источники +
реестр полей форм**. Всё здесь — **PII-free** (не содержит персональных данных
заявителя). Это отправная точка; актуальные значения движок **перепроверяет
вживую** во время `dnv-research` (R9).

> ⚠️ **Это НЕ юридическая консультация и не официальный текст.** База —
> датированный дистиллят из открытых источников. Формы, суммы и процедуры
> **меняются**; всё процедурное/пороговое помечено «(проверить вживую)».
> «Telegram = мнение, не закон.»

## Структура

| Каталог | Что | Роль в проекте |
|---|---|---|
| `norms/` | Разбор норм (Ley 14/2013 и др.) с **as-of** датами, **переякоренный на `sources/primary/`** | вход для `dnv-research` / `dnv-synthesis`; вживую сверяются суммы и процедуры |
| `practice/` | **Обезличенный агрегированный дайджест** Telegram-сообществ (без сырых сообщений, имён и псевдо-ключей) | вход для синтеза + верификации (мнение, не норма) |
| `sources/` | **`primary/`** — дословные тексты законов и Instrucción (BOE); `reports/` — 4 AI-отчёта + отчёт по правоприменению; `youtube-consultant/` и `telegram-consultant/` — публичные каналы (провенанс → роль, без имён) | `primary/` — якорь `[норма]`; остальное — вход для верификации `devils-advocate` |
| `forms/` | Реестр полей форм MI-T/MI-F/tasa (`registry.json`) — общий namespace с профилем | питает `dnv-documents` (генерация) и `dnv-review` (field-QA) |

> 🔎 **С 2026-07 у базы есть первичный апстрим.** Раньше `norms/` был дистиллятом
> четырёх AI-отчётов ~марта 2026 — слоя, который сам по себе содержит отменённый
> RD 557/2011 и несуществующий «RD 1155/2020». Датирование измеряло свежесть копии,
> а не её **верность**. Теперь нормы якорятся на **`sources/primary/`** — дословный
> текст с BOE и `inclusion.gob.es`, лежащий в репо, с датой извлечения. При
> расхождении норм-файла и `primary/` **прав `primary/`**. Подробности —
> `sources/primary/README.md` и таблица переякоривания в `norms/README.md`.

## Шкала достоверности (единая для всей базы и spec)

| Тег | Значение | Где живёт первоисточник |
|---|---|---|
| `[норма]` | Текст закона / нормативного акта (Ley, Real Decreto, BOE) | **`sources/primary/`** — дословно |
| `[официальное разъяснение]` | Разъяснение/критерий гос. органа (UGE-CE, DGM, Instrucción) | `sources/primary/instruccion-conjunta-2023.md`; сводка и FAQ UGE-CE — через `sources/reports/2026-07-aplicacion-practica.md` |
| `[практика — консультант]` | Публичные каналы консультанта | `sources/youtube-consultant/`, `sources/telegram-consultant/` |
| `[практика — Telegram]` | Обезличенный дайджест сообществ (`practice/`) — **мнение, не норма** | `practice/digest.md` |
| `[не подтверждено]` | Корроборации не найдено — нужна внешняя проверка | — |

> **Проверка тега `[норма]`:** claim, который не подтверждается дословным текстом в
> `sources/primary/`, тег `[норма]` нести **не может** — максимум
> `[официальное разъяснение]`. Это то, что стало проверяемым после переякоривания.

**Правило апгрейда:** `[практика — Telegram]` **никогда** не поднимается до
`[норма]` количеством сообщений — только текст закона / официальное разъяснение
меняет уровень (см. `.claude/agents/devils-advocate.md`).

## Датированность

- Каждый норм-файл несёт **`as-of: YYYY-MM`** в заголовке; каждый файл в
  `sources/primary/` — **дату извлечения** и URL консолидированной редакции.
- Всё **процедурное и пороговое** (окна подачи, суммы SMI, эпиграфы tasa,
  ярлыки форм, состав пакета, фактические сроки) помечено **«(проверить вживую)»**.
- Если содержимое старше текущего года и не подтверждено живым рисёрчем — движок
  флагует «(проверить вживую)» в `user/spec.md` и не подаёт его как факт.
- **Устарело → архивировать.** Апдейты базы **не гарантируются** сопровождающим;
  живой рисёрч (`dnv-research`) — основной механизм актуализации.

**Два уровня, которые важно не смешивать.** После переякоривания область живого
рисёрча **сузилась**:

| Слой | Стабильность | Нужен ли живой рисёрч |
|---|---|---|
| **Что написано в законе** — статьи, формулировки, проценты | стабильно; лежит дословно в `sources/primary/` | **нет** |
| **Суммы и текущие процедуры** — SMI, эпиграфы/суммы tasa, состав пакета, бланки, фактические сроки, доступность cita | меняется, часть — ежегодно | **да, обязательно** |

Правило **«фальшивая свежесть хуже честной датировки»** остаётся в силе: `as-of`
поднимается только у файлов, которые реально пересмотрены, — не у всех подряд «для
порядка».

## Метки архетипа

Контент помечен **`case-derived`** (выведено из архетипа v1: autónomo/контрактор +
cónyuge) vs **`generic`** (применимо ко всем кейсам DNV). Иные формы занятости/
семьи — вне v1.

## Приватность

- `practice/` — **только** агрегированный дайджест: тегированные утверждения +
  band по числу *разных* людей + период. **Нет** сырых сообщений, имён,
  идентификаторов, псевдо-ключей; единичные авторы подавлены (k-анонимность).
- `sources/youtube-consultant/` — **публичные** транскрипты; имя ведущей снято,
  роль = «публичный YouTube-канал консультанта».
- **Приватные консультантские чаты не входят как источник в любом виде** (R5).
