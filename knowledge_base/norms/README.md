# knowledge_base/norms/ — дистиллят норм (датированный)

PII-free дистиллят правовых норм для DNV (*teletrabajo de carácter
internacional*). Каждый файл несёт **`as-of`** дату в заголовке. Это **не**
официальный текст — сверяйте с BOE / sede вживую.

> ⚠️ **Общий as-of дистилляции: 2026-06** (`tie-huellas.md` — 2026-07).
> Дистиллировано из `../sources/reports/` (4 AI-research-отчёта, ~март 2026) и
> публичных транскриптов. Всё **процедурное и пороговое** помечено «(проверить
> вживую)». SMI/суммы/эпиграфы/окна/ярлыки форм меняются — `dnv-research`
> перепроверяет их на дату запуска.

## Действующий регламент (сверка 2026-07)

**Reglamento de Extranjería — это `RD 1155/2024`** (BOE-A-2024-24099, в силе с
**20.05.2025**), заменивший **`RD 557/2011`**; уже изменён **`RD 316/2026`**
(в силе с 16.04.2026). Прежние редакции этой базы местами якорились на
отменённый RD 557/2011 — это исправлено.

> Ядро DNV — **законы** (Ley 14/2013 гл. V bis + Ley 28/2022), и смена регламента
> их не двигает: у раздела movilidad internacional своего регламента нет, общий
> применяется **субсидиарно**. Поэтому аудит был точечным, а не сплошным.

## Конвенции файлов

- Заголовок каждого файла: `> as-of: YYYY-MM · <охват>`.
- Теги достоверности на каждом утверждении (см. `../README.md`).
- Метки `case-derived` / `generic`.
- Ссылка на источник дистилляции (`../sources/...`) там, где утверждение выведено
  из отчёта, а не из первичного текста закона.

## Как читает движок

`dnv-research` читает эти файлы, **surface'ит as-of даты** в `user/spec.md`, и для
всего помеченного «(проверить вживую)» делает живой рисёрч через веб-поиск
на дату запуска. `devils-advocate` сверяет claim'ы
spec против этих файлов + web, уважая as-of (старше текущего года на процедурном →
`OUTDATED`).
