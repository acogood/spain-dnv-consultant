# `knowledge_base/practice/` — обезличенный дайджест практики

Это **единственный** chat-производный артефакт, который попадает в публичный
репозиторий. Здесь нет сырых сообщений, идентификаторов, имён авторов и
псевдо-ключей — только курируемые утверждения + грубый band «по теме
высказывались» (число *разных* людей) + период.

## Что это и что это НЕ

- ✅ Агрегированный сигнал: какие темы и наблюдения встречаются в публичных
  сообществах заявителей DNV.
- ❌ **Не закон, не официальное разъяснение, не голосование.** Telegram = мнение.
  band отражает, сколько *разных* людей затрагивали тему (корроборация), а не
  сколько «подтвердили» утверждение. Каждый пункт сверяйте с
  `knowledge_base/norms/`.

## Файлы

| Файл | Что это |
|---|---|
| `digest.md` | человекочитаемый дайджест по темам |
| `digest.json` | то же, машиночитаемо (потребляется синтезом/верификацией) |
| `LAST_COVERED_DATE` | дата, до которой покрыта практика — дальше домайнивайте свой «хвост» |
| `curation.json` | провенанс: курируемые утверждения + регэкспы-дискавери (вход для регенерации) |

## Приватность (как это гарантируется)

1. **Анонимизация локально** (`engine/scripts/chat/anonymize_chat.py`):
   keep-allowlist полей `{id, date, text, reply_to, topics}` + псевдоним =
   salted-hash `from_id` (соль локальная и секретная, в `user/`, не
   публикуется). Имена авторов и контактные данные вычищаются из текста.
2. **Агрегация** (`engine/scripts/chat/build_digest.py`): counts по *разным*
   псевдонимам, **k-анонимность** (пункты с поддержкой ниже порога
   отбрасываются), counts отдаются **band'ами**, а не точными числами.
   Псевдонимы и сырой текст в публикуемый дайджест **не попадают**.

## Регенерация / догрузка «хвоста»

Дайджест датирован (`LAST_COVERED_DATE`). Чтобы добавить свежую практику:

```bash
# 1) обезличить свои свежие выгрузки (вывод остаётся в user/, gitignored)
python engine/scripts/chat/anonymize_chat.py <raw_export.json> user/anon/<name>_anon.json \
    --salt-file user/anon/.anon_salt --allowed-root .

# 2) (опц.) обновить curation.json своими утверждениями/регэкспами

# 3) пересобрать дайджест
python engine/scripts/chat/build_digest.py --curation knowledge_base/practice/curation.json \
    --slices user/anon/*_anon.json --out-dir knowledge_base/practice --allowed-root . --min-authors 3
```

> **Этот сид построен регэксп-дискавери** (band = число разных людей, чьи
> сообщения соответствуют теме). Уточнение до id-level курации — задача
> верификации (`dnv-verify`) и расширения базы.
