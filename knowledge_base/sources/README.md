# knowledge_base/sources/ — первичные источники (провенанс → роль)

Первичный материал для дистилляции норм (`../norms/`) и для верификации
claim'ов агентом `devils-advocate`. **Деперсонализировано.**

> Провенанс фиксируется как **роль**, а не как персона. Имена авторов сняты.
> Отчёты — это **обезличенные примеры** deep-research по типовому кейсу
> (archetype), а не досье реального человека: конкретные даты и идентификаторы
> кейса удалены либо заменены плейсхолдерами `{{…}}` (напр.
> `{{дата истечения TIE}}`), под которые вы подставляете свои значения.
> Персональных данных заявителя, супруги или третьих лиц здесь нет.
> Приватные консультантские чаты **не входят** сюда в любом виде (R5).

## `reports/` — AI-research-отчёты (4)

Отчёты глубокого исследования одного и того же (обезличенного, типового)
правового кейса DNV (*teletrabajo de carácter internacional*) четырьмя
инструментами, под разными углами. Русский с испанскими терминами.

| Файл | Инструмент | Роль |
|---|---|---|
| `report-chatgpt-deep-research.md` | ChatGPT Deep Research | вторичный анализ норм + практики |
| `report-claude.md` | Claude | вторичный анализ норм + практики |
| `report-gemini.md` | Gemini | вторичный анализ норм + практики |
| `report-perplexity.md` | Perplexity | вторичный анализ норм + практики (с цитатами) |

**Как использовать:** это вторичные аналитические источники, не первоисточник
права. Для `[норма]` всегда сверяйте с текстом закона (BOE) вживую. При
расхождении отчётов между собой — фиксируйте в spec §11 «Расхождения».

## `youtube-consultant/` — публичный YouTube-канал консультанта (4 транскрипта)

Транскрипты публичных видео консультанта по ВНЖ. **Имя ведущей снято**; роль =
«публичный YouTube-канал консультанта» (тег `[практика — консультант]`).

| Файл | Тема |
|---|---|
| `renovacion-strategiya-2026.md` | Стратегия продления 2026, окно подачи |
| `renovacion-razbor-nyuansov.md` | Разбор нюансов продления, документы |
| `vyros-trebuemyj-dohod.md` | Повышение требуемого дохода (SMI 2026) |
| `anulacion-vnzh-nomada.md` | Аннулирование ВНЖ — риски (слова vs практика) |

**Статус:** `[практика — консультант]` — экспертное мнение практикующего
консультанта, **не** норма и не официальное разъяснение. Полезно для контекста и
для того, «на что смотрит администрация», но проверяется против нормы.

## Что НЕ является источником

- **Приватные консультантские чаты** — исключены полностью (нет согласия, не
  публикуемо). Ни один claim не должен трассироваться к ним.
- **Персональные документы заявителя** — живут в `user/` (gitignored), в базу не
  попадают.
