# `user/` — ваше локальное рабочее пространство (НЕ коммитится)

Здесь живут все ваши персональные данные и результаты работы движка. **Всё
содержимое этой папки исключено из git** (см. корневой `.gitignore`), кроме
этого README и файлов-схем `*.example`. Ваши данные остаются на вашем диске и
никогда не попадают в публичный репозиторий.

> ⚠️ **Не редактируйте `.gitignore`, чтобы «добавить» сюда файлы в git, и не
> делайте `git add -f` для содержимого `user/`.** Это единственная защита,
> которая работает всегда.

## Что сюда кладёте вы

- свои документы (контракты, выписки, справки, сканы);
- свежие выгрузки чатов (Telegram JSON), от которых движок локально берёт
  «хвост» практики.

## Что движок создаёт здесь

| Файл / папка | Кто пишет | Назначение |
|---|---|---|
| `case-profile.json` | `dnv-intake` | структурированный профиль кейса (единый источник правды) |
| `pipeline-state.json` | все `dnv-*` | состояние пайплайна для возобновления между сессиями |
| `spec.md` | `dnv-synthesis` | единый источник правды с тегами достоверности |
| `slices/` | `dnv-chat-mining` | локально намайненные срезы практики по темам |
| `verification_report.md` | `dnv-verify` | вердикты по claim'ам |
| `drafts/` | `dnv-documents` | заполненные черновики документов |
| `tracking.md` | `dnv-tracking` | журнал ведения кейса после подачи (даты, дедлайны, «что делать сейчас») |

## Файлы-схемы

Рядом с реальными файлами движок хранит `*.example`-версии (например
`case-profile.json.example`). Они **показывают структуру** и коммитятся как
документация — реальных значений в них нет.
